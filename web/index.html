Data-Cleaning Tool

Cleans messy CSV and Excel exports reproducibly from a YAML profile, with a rejects file and an HTML report. Version 0.1.0, shown here on an invented survey export of a fictional panel research company.

  • Reads CSV and Excel the same way every time: encoding and delimiter sniffing, header offsets, footer rows, several sheets, short and malformed records.
  • Normalises headers to snake_case and cleans text: Unicode form, invisible characters, whitespace, null tokens, case and value maps.
  • Converts types with German and English number and date formats; a value that does not parse is rejected or, where the profile says so, set to null; never guessed.
  • Removes exact and key duplicates (fuzzy matching as an option), fills missing values per column and checks ranges, patterns and allowed values.
  • Writes the cleaned file (CSV, Excel or Parquet), every removed row with its reason, and a JSON and HTML report with before and after statistics.

Install and run

Install the command from the release wheel with uv, extras included:

uv tool install "data-cleaning-tool[fuzzy,parquet] @ https://github.com/HARISPAARTAN/data-cleaning-tool/releases/download/v0.1.0/data_cleaning_tool-0.1.0-py3-none-any.whl"

Or work from a clone, which also has the fixtures and profiles used below:

git clone https://github.com/HARISPAARTAN/data-cleaning-tool.git && cd data-cleaning-tool && uv sync --all-extras

In a clone, put uv run in front of each clean-data command. The extras are optional: fuzzy (rapidfuzz) for fuzzy de-duplication, parquet (pyarrow) for Parquet output.

Exit codes

exitmeaning
0success; a run without --strict may still have rejects
1internal error (a bug); run again with --log-level debug
2usage or profile error, a profile that cannot run chunked, a missing extra
3input error: missing or undecodable file, no matching sheet, a profile column absent
4quality gate: --strict or quality.max_reject_rate; rejects and reports written, output not
5output error: target not writable, Excel row limit exceeded
130interrupted; temporary files removed
